# .github

This is the special `.github` repository of the **AIM Newsroom** organization on GitHub. It is public, and it holds what the organization shows to everyone.

## What is in here

| Path | What it does |
|---|---|
| [`profile/README.md`](profile/README.md) | The text on the organization's public page, [github.com/AIM-Newsroom](https://github.com/AIM-Newsroom) |
| [`profile/banner-light.svg`](profile/banner-light.svg), [`profile/banner-dark.svg`](profile/banner-dark.svg) | The AIM banner used by the profile, in a light and a dark version |
| `README.md` | This file, for people who open the repository itself |

## The product

AIM is newsroom automation: it collects news, writes a draft, checks it, fixes what it can, and then waits for a person to send it. The product code is in a private repository; this one is only the public face.
